ORGANIZAÇÃO DOS ARQUIVOS
- css/style.css: define cores, fontes, tamanhos, espaçamentos, cartões, efeitos e adaptação para celular.
- js/script.js: abre e fecha o menu em telas pequenas.
- assets/img: fotografias e imagens utilizadas nas páginas.
- assets/videos: pasta reservada para vídeos.
- assets/documentos: pasta reservada para relatórios e documentos.

COMO ENTENDER ALGUNS COMANDOS
HTML
- <header>, <nav>, <main>, <section>, <article> e <footer> organizam semanticamente o conteúdo.
- href define o destino de um link.
- src indica o caminho de uma imagem.
- alt descreve a imagem para leitores de tela e quando ela não carrega.
- aria-current identifica a página atual; aria-expanded informa se o menu está aberto.

CSS
- :root guarda variáveis reutilizáveis, como cores e medidas.
- display: flex alinha elementos em uma linha ou coluna.
- display: grid organiza elementos em linhas e colunas.
- padding é o espaço interno; margin é o espaço externo.
- border-radius arredonda os cantos.
- transition suaviza mudanças visuais.
- :hover aplica um estilo quando o ponteiro passa sobre um elemento.
- @media adapta o layout a diferentes larguras de tela.

JAVASCRIPT
- getElementById seleciona um elemento pelo ID.
- addEventListener registra uma ação, como um clique.
- classList.toggle adiciona ou remove uma classe CSS.
- setAttribute altera um atributo HTML, como aria-expanded.
- querySelectorAll seleciona vários elementos; forEach percorre a lista.
